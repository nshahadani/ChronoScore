# ChronoScore
A real time, score tracker featuring points scored by the players, with a countdown tempo timer.

Preview
<img width="1920" height="1128" alt="image" src="https://github.com/user-attachments/assets/ee5100f1-d026-4d7b-bb53-98048f930d90" />

Features
* Dual player/team score counters (+1, +2, +3 point buttons)
* Integrated real-time countdown timer tracking raw seconds
* Dedicated instant game reset function
* Responsive design styled for mobile and desktop screens
